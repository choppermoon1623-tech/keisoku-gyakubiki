計測・制御 逆引きシステム

「やりたいこと」から、使うセンサとアクション装置を探そう（中学校技術科・問題解決）

こんな言葉でさがせます → くらい / ひとがくる / あつい / みず / おと / ドアがあいた / 火事 / 知らせたい / 回したい

計測・制御は センサ（気づく）→ プログラム（判断する）→ アクション装置（動かす） の流れ。センサが得た値を、プログラムが条件と比べて判断します。まず「何が分かれば困りごとを解決できるか」を考えよう。

気づきたい・調べたい（入力・計測）

動かしたい・知らせたい（出力・動作）

見つかりませんでした。ちがう言い方でためしてみよう。
（例：「あつい」「さむい」「ひかり」「うごき」「におい」「しらせる」）

石川研究室の授業資料をもとに整理した例です。説明には、このアプリで補った設計のヒントも含みます。同じしくみを自分のテーマに置きかえて考えてみよう。

アイデアを形にするには、困りごと → 測るもの → 判断 → 動作 → 確かめ方をつなげよう。試して分かったことをもとに、前の段階へ戻っても大丈夫。
